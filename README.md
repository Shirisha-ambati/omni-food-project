# omni-food-project
🍽️ Omnifood – AI-Based Food Subscription Website
📌 Project Overview

Omnifood is a modern, responsive website for an AI-powered food subscription service that delivers healthy meals tailored to user preferences.

The platform focuses on solving real-world problems like lack of time for cooking and unhealthy eating habits by providing personalized meal plans and doorstep delivery.

“A healthy meal delivered to your door, every single day.”

🚀 Features
🍱 Personalized AI-based meal plans
📅 365-days subscription model
🥗 Supports multiple diets (Vegan, Keto, Gluten-free, etc.)
🚚 Daily meal delivery
⏸️ Pause subscription anytime
🌱 Organic & eco-friendly packaging
📱 Fully responsive design
🛠️ Tech Stack

CSS3
JavaScript
Ionicons (for icons)
Google Fonts (Rubik)
